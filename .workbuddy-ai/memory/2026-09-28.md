### 五个用法坑（全部静默失败，不报错）

**这些是接入时最容易踩的，且共同点是控制台完全干净：**

1. **`createLayout` 动的是独立的 `translate` 属性，不是 `transform`。**
   读 `transform` 会判定"没动"。同一个坑在 `core/motion.ts` 的 `--m-rise` 也踩过。
2. **`scrambleText` 属性名必须写 `textContent`。** 写 `text` 静默无效。
3. **`createDrawable` 要把返回值交给 `animate()`，不能传选择器。**
   正确：`animate(createDrawable(sel), { draw: [...] })`。
4. **`createMotionPath` 返回普通对象**，`...mp` 展开进 `animate` 的 params。
   在 SVG 元素上读 `computed translate` 量不到（它改的是 `transform`）。
5. **`createDraggable` 的 `container` 不能设成元素自己**，可移动空间为 0。

**推论：这类 API 不能用"跑起来没报错"验收，必须量最终数值。**

### anime.js v4 vs v3 —— 网上教程必错

v3 是 `anime({...})`；v4 是 `animate()` / `createTimeline()` / `createScope()`。
网上绝大多数教程仍是 v3，**照抄必错且不报错**。eslint 的 `no-restricted-imports`
护栏（animejs 只能从 `src/core/motion.ts` 导入）必须保持。

### 判据：什么该用 anime.js

问「这个动画的**输入**是什么」：
- 输入是 **CSS 状态**（hover / class）→ 用 CSS
- 输入是 **连续量或运行时数据**（指针、滚动、字数、列表长度、接口结果）→ 用 anime.js
- 输入是 **无**（纯装饰循环）→ 用 CSS

anime.js 接管不了 `:hover` / `:focus` 伪类 —— 硬改必然产生"同一件事两份实现"。

### 仓库盘点（准确口径）

- 35 个 keyframes：**30 在用，5 个死代码**（`party-bounce` /
  `party-confetti-fall` / `party-spin-slow` / `party-card-flip` / `party-scale-in`）

- 第二档 20 处 = 9 处 `animate-[...]` + 5 处 `mini-bar` 内联 + 3 个 `party-anim-*` + 3 处唱片/拍立得内联

**注意：`party-pulse-glow` 是活的**（`GameAvatar.tsx:62` 用 Tailwind 任意值引用）。
我最初用 `grep "\b$k\b"` 数成 0 引用 —— **`\b` 在 `glow_2s` 这种 `_` 处不成立**
（`_` 是 word 字符），差点误报成死代码。**数引用要用子串匹配，不要用 `\b`。**
